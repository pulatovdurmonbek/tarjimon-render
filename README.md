# tarjimon-render

**Adabiy Tarjimon AI** botining video montaj ishchisi (GitHub Actions). Bot `repository_dispatch` (`render`) yuboradi:
ssenariy sahnalari → FLUX rasmlar (Pollinations, bepul) → FFmpeg (pan/zoom + o'zbekcha ovoz + subtitr) → MP4 → Supabase Storage → bot foydalanuvchiga yuboradi.
Bu repoda hech qanday maxfiy kalit saqlanmaydi: barcha havolalar vaqtinchalik (2 soat).
